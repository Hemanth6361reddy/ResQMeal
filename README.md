# ResQMeal 🍲

> A real-time, mission-critical food rescue platform connecting food donors, NGOs, and delivery partners.

## Core Tech Stack
- **Frontend**: React, TypeScript, Vite, Tailwind CSS, shadcn/ui, TanStack Query, Mapbox GL JS
- **Backend**: Python 3.11+, FastAPI, WebSockets, SQLAlchemy, Pydantic
- **Database**: PostgreSQL with PostGIS extension
- **Cache & Real-time**: Redis
- **DevOps**: Git, Docker, GitHub Actions

## Project Structure
- `frontend/` - React + Vite Web Client
- `backend/` - FastAPI REST API & WebSocket Server
